# atividade6
Principais funções do GITHUB
GitHub: Além de compartilhar para que todos possam ver,ele permite que todos possam contribuir,através dele,desenvolvedores do mundo inteiro podem sugerir melhorias no seu código de forma organizada.

Pricipais funções do GIT
Git : Ele não só organiza,ele é a prova de falhas,ele garante que você possa experimentar coisas novas sem medo de quebrar o projeto inteiro,já que o histórico é imutável e fácil de restaurar.

Resumo:
É como se o Git fosse o seu caderno de rascunhos e anotações super organizado,e o GitHub fosse a biblioteca pública onde você publica esse caderno para outros lerem,comentarem e até ajudarem a escrever as próximas páginas.
